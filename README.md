# Eddy Arriaga-Barrientos · Portfolio

[View the portfolio on GitHub Pages](https://eddyarriaga00.github.io/Portfolio-Website/).

This static site showcases selected software projects, experience, and contact information. Project screenshots come from the live demos. The footer has an optional audio player.

## Run locally

Serve the repository root with `python3 -m http.server 8000`, then open http://localhost:8000.

GitHub Pages publishes from the root of `main`. There is no build step.
